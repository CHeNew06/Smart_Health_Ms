设计说明 - 登录页

页面定位

登录页是用户进入系统的第一个页面，需要传达专业、可信赖的医疗健康品牌形象。

视觉设计

  • 顶部使用蓝色渐变背景，搭配心跳图标强化健康主题
  • 白色内容区域使用圆角上浮效果，增加层次感
  • 输入框带图标前缀，降低用户认知负担

交互设计

Tab切换 倒计时 密码显隐
  • 双模式Tab切换：账号密码 / 验证码登录
  • 获取验证码按钮点击后60秒倒计时
  • 密码输入框支持显示/隐藏切换
  • 记住密码 + 忘记密码快捷入口

适老化考虑

  • 按钮和输入框高度 44px，满足触摸目标最小尺寸
  • 字体大小不低于 13px，确保可读性
  • 颜色对比度符合 WCAG AA 标准

开发对接

API
  • 登录接口：POST /api/auth/login
  • 发送验证码：POST /api/auth/send-code
  • 验证码登录：POST /api/auth/login-by-code
  • 第三方登录：OAuth2 对接微信/QQ
